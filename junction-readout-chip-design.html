Microwave engineering and device layout

Junction readout and chip design for superconducting quantum devices.

This page collects the hardware-facing side of the research: microwave resonator design, Qiskit Metal automation, GDS layout generation, and chip-design experiments aimed at connecting junction physics to practical readout structures.

Readout Direction

The project folders include low-impedance resonator notebooks, junction-readout GDS files, and reusable Python helpers for geometry and component generation.

Resonators

Microwave resonator design

Design notebooks explore lumped and low-impedance resonators, with an eye toward impedance, coupling, footprint, and fabrication-ready layout.

Qiskit Metal

Reusable design tooling

The MicrowaveDesign package provides editable helpers for Qiskit Metal geometry, components, and project setup so layout iterations can be scripted instead of redrawn manually.

GDS

Chip layout workflows

GDS outputs track design iterations for resonators, dicing markers, chip layouts, and junction-oriented readout structures.
