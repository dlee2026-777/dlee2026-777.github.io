# GitHub Pages Research Template

This folder contains a simple static research site for GitHub Pages.

## Pages

- `index.html`: intro page for your own writing
- `mtjj.html`: MTJJ research summary
- `junction-readout-chip-design.html`: junction readout and chip-design summary

## Publish

1. Replace `Your Name` and any placeholder links.
2. Push this repository to GitHub.
3. In the repository settings, enable GitHub Pages from the `docs/` folder on your chosen branch.

## Update Figures

The page currently uses copied MTJJ figures in `docs/assets/`:

- `euler-curvature-reference.png`
- `wilson-spectrum.png`
- `tomography-comparison.png`

Swap these files or edit their captions in `index.html` as your best public-facing results change.
